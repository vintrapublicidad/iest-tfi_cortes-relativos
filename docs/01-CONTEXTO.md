# Contexto del Proyecto

## Problema

Los clientes de una peluquería en Tinogasta pueden perder tiempo consultando por teléfono o WhatsApp si existen turnos disponibles. Además, cuando un cliente no confirma su asistencia, pueden quedar espacios vacíos en la agenda y perderse oportunidades de atención.

## Objetivo

Crear un sitio web que permita consultar servicios, peluqueros y disponibilidad, seleccionar un día y horario y solicitar un turno. El sistema debe contemplar un recordatorio por WhatsApp y un mecanismo de confirmación para reducir ausencias y liberar turnos que no sean confirmados.

## Público objetivo

Familias, niños y adultos de Tinogasta, Catamarca, que buscan reservar un servicio de peluquería de manera rápida y sencilla.

El diseño debe priorizar especialmente:

- Uso desde celulares.
- Lectura clara.
- Pocos pasos para reservar.
- Información visible antes de confirmar.
- Mensajes simples y directos.

| Corte y barba | 60 min | $ 0 |

Los precios son valores provisorios para la documentación del proyecto y deben reemplazarse cuando existan datos reales.

## Alcance inicial

El sistema permitirá:

- Consultar los servicios.
- Consultar peluqueros y disponibilidad.
- Seleccionar fecha y hora.
- Solicitar un turno con nombre y WhatsApp.
- Respetar una anticipación mínima de 10 horas.
- Enviar recordatorio por WhatsApp.
- Registrar la confirmación.
- Cancelar un turno.
- Utilizar una lista de espera cuando corresponda.

## No incluye (por ahora)

- Pago online con tarjeta.
- Cuentas de usuario con contraseña.
- Venta online de productos.
- Gestión de stock.
- Programa de fidelización.
- Sistema de facturación.
- Aplicación móvil nativa.

## Restricciones y supuestos

- Los precios y horarios reales deberán ser definidos por el emprendimiento.
- Los nombres de peluqueros utilizados en ejemplos son datos de demostración.
- La integración de WhatsApp dependerá del servicio o API seleccionado.

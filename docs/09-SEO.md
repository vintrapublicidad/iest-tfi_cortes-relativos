## Palabras clave

- turnos peluquería Tinogasta
- reservar turno online
- peluquería Tinogasta
- corte de pelo Tinogasta
- peluquería Catamarca
- reservar peluquería

Las palabras clave deben incorporarse naturalmente y no repetirse de manera artificial.

## Imágenes y texto alternativo

El logo debe utilizar un texto alternativo descriptivo, por ejemplo:

```html
alt="Logo de Cortes Relativos con ilustración inspirada en Einstein y elementos de peluquería"
```

Las imágenes decorativas que no aporten información deben utilizar un alt vacío cuando corresponda.

## HTML semántico

Utilizar correctamente las etiquetas:

```html
<header>
<main>
<section>
<nav>
<footer>
```

## Encabezados

- Mantener una jerarquía lógica de encabezados.
- Utilizar un único h1 principal por página.
- Utilizar h2 y h3 para organizar las secciones.

## Idioma

La página debe declarar español como idioma principal:

```html
<html lang="es">
```

## Rendimiento

Objetivos iniciales:

- Buen rendimiento en dispositivos móviles.
- Imágenes optimizadas.
- Evitar recursos innecesariamente pesados.
- Buscar una puntuación de PageSpeed de 90 o superior cuando sea viable.
